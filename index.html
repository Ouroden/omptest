omp

Oh My Pi — a terminal coding harness

What is omp?

Oh My Pi (omp) is a terminal-based coding harness. It pairs a coding model with a rich tool environment so it can read, edit, and run real code inside your projects.

Capabilities

  • File tools — read, edit, and write files with line-anchored, structured edits.
  • Shell execution — run builds, tests, and arbitrary commands in a persistent shell.
  • Code intelligence — LSP-powered navigation: definitions, references, renames, and diagnostics.
  • Code search — fast globbing and regex grep across the codebase.
  • Web access — fetch and search the web for docs and current information.
  • Subagents — delegate multi-step work to background agents and coordinate them.
  • Long-running processes — start, monitor, and drive servers, watchers, and REPLs.

Why a harness?

A chat model alone can talk about code. A harness lets it do the work: reproducing a bug, applying a patch, running the test suite, and verifying the fix — end to end, without leaving your terminal.
